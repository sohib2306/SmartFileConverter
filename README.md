# Smart File Converter Suite

**Smart File Converter Suite** is a simple and user-friendly file conversion tool that doesn't require programming knowledge.

Smart File Converter Suite allows users to convert files quickly and efficiently without the need to install complex software. All conversions are fast and easy to use with minimal effort.

### Demo Version Features:
- 📊 Convert Excel to CSV
- 📑 Convert CSV to Excel
- 📦 Create ZIP archive from a file
- 📷 Convert image files (JPG, PNG) to PDF
- 🎵 Extract audio from video files (MP4, AVI, and more)

## Installation

1. Download `SmartFileConverterSuite_demo.exe` from [this page](https://github.com/sohib2306/SmartFileConverter/releases/tag/v1.0-demo).
2. Run the file — no installation required, the program works directly!

## Supported Operating Systems

- Windows 10/11

## Usage

After downloading and launching the program:

1. Select the file you want to convert (Excel, CSV, image, video).
2. Choose a folder to save the converted file.
3. Select the operation you want to perform:
   - Convert Excel to CSV
   - Convert CSV to Excel
   - Create a ZIP archive
   - Convert images to PDF
   - Extract audio from video files
